Privacy Policy

Last updated: September 6, 2026 · Effective for the Finance Agent Google Cloud application

Finance Agent (“the application,” “we”) is an LLM tool used by an NJIT student organization to read the club’s official budget Google Sheet and to file receipt evidence in Google Drive. This policy explains what information the application uses, why, and how it is handled. We keep zero data on our servers.

Who this application is for

The application is operated for authorized officers and members of the student organization that deployed it. It is not a consumer product and is not offered to the general public. It is designed to be called as a tool by a language-model assistant (for example the club’s sms-agent). End users do not create a separate Finance Agent account.

Information we access

When an authorized operator grants Google access, the application may use:

  • Google Sheets data from the organization’s budget workbook — event headers, line items, planned and actual amounts, flags, and notes — in order to list events and line items.
  • Google Sheets write access limited to appending a row on the receipts tab (event, line item, Drive link, timestamp, filename). The application does not overwrite planned or actual budget figures.
  • Google Drive file content when a receipt image is uploaded — the photo or file itself, a generated link, and basic file metadata such as name and time of upload.
  • Google account identity to the extent required to complete OAuth (for example, to confirm the authorizing account and apply the organization’s sharing rules).

Receipt files are shared with people signed in as @njit.edu (NJIT Workspace), not with the open internet.

How we use information

Google user data is used only to provide the finance features the organization requested:

  • Return the list of events and line items already present on the official sheet.
  • Store a receipt file and attach evidence to the matching receipts-tab row.
  • Allow treasurers and reviewers to open that evidence from the same workbook they already audit.

The application does not use Google user data for advertising, does not sell it, and does not use it to train unrelated models. It does not create a shadow budget.

Google API Services / Limited Use

Finance Agent’s use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

We keep zero data on our servers

Finance Agent does not store Google user data, budget contents, receipt images, or copies of spreadsheet rows on our servers. There is no application database and no shadow ledger. Data is read from or written to Google APIs to complete a tool call, then discarded. After a request finishes, our servers hold zero user data.

Budget numbers continue to live in the organization’s Google Sheet. Receipt images live in the organization’s Google Drive. Those Google products are the only systems of record.

Data is shared only as needed to provide the service: with Google (Sheets and Drive), with organization officers who already have access to those files, and with NJIT accounts under the Drive sharing setting described above. We do not sell personal or Google user data.

Retention follows the organization’s own Sheet and Drive practices. A receipt row or file remains until an organization officer deletes it from Google Drive or the workbook. Because we keep nothing on our side, there is no separate copy for us to retain or export.

Your choices and deletion

Authorized operators can revoke the application’s Google access at any time in their Google Account permissions. Revoking access stops new API calls; it does not by itself delete rows or files already written to the organization’s Sheet or Drive. We have no server-side copy to delete.

To correct or delete a receipt file or log row, contact an organization officer who administers the budget workbook (typically the treasurer). They can remove the Drive file and the corresponding receipts-tab row.

Security

Access is limited to the Google APIs required for the features above. Concurrent receipt uploads are serialized so two writers do not overwrite each other’s append. The application does not make receipt files public. Officers should continue to follow NJIT and OSIL handling rules for financial records.

Children

The application is intended for college student-organization officers and is not directed at children under 13. We do not knowingly collect information from children under 13.

Changes

If this policy changes in a material way, we will update the date at the top of this page. Continued use of the application after an update constitutes notice to operators of the revised policy.

Contact

Questions about privacy or Google user data should go to the student organization officers who operate Finance Agent, or to the support email listed on the application’s Google Cloud OAuth consent screen. This website is the application homepage for that Google Cloud project.
