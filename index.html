<what-it-does>

LLM tool not a chatbot with a spreadsheet hobby

Built to be invoked by a language model — list events, list line items, upload a receipt. The model isn’t inventing a budget. It’s calling this service, which is staring at the same cells the treasurer uses.

Year at a glance live actual tab

Returns every event already on the sheet, in the treasurer’s order. If it’s on the budget, it’s in the list. No second calendar.

Zoom into one event planned · actual · notes

Ask for an event and see line items. Subtotals are skipped. Ambiguous names resolve to the line item, not a guess at the whole night.

File a receipt drive link on the receipts tab

A photo is stored in Google Drive. A row is appended: event, line item, link, timestamp, filename. Evidence is attached. Budget numbers are never overwritten.

Zero data on our servers nothing persisted

No copies of the sheet, no receipt images, no shadow ledger. After a request finishes, our servers hold zero user data. Sheets and Drive are the only systems of record.

NJIT stays in the org @njit.edu visibility

Receipts are visible to people signed in as @njit.edu — the same campus share you’d pick in Drive. Not posted to the open internet.

<how-it-works>

01 · an LLM calls the tool

Expose Finance Agent to any language-model assistant: list events, list line items, upload a receipt. The club’s sms-agent is one such caller.

02 · sheets and drive stay canonical

Google Sheets remains the official budget. Google Drive stores the image. Automation is not a shadow ledger and does not invent events that aren’t headers on actual.

03 · treasurers reconcile in place

Officers send a picture and get a link that lands on the right row. Two people dumping receipts at once don’t clobber each other — the sheet gets one append at a time.

<google-access>

Google Cloud application used as an LLM tool by authorized officers. It requests Google authorization only to operate on the org’s existing finance files. We keep 0 data on our servers.

  • Google Sheets — read the live budget (actual) tab; append receipt log rows. Planned and actual amounts are not rewritten.
  • Google Drive — store receipt photos and return a link the treasurer can open from the sheet they already audit.
  • No server-side store — budget rows, receipt files, and Google user content are not retained on Finance Agent servers.
  • Domain restriction — receipt files are shared with the NJIT Workspace (@njit.edu), not made public.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. See privacy and terms.

  • keeps zero data on our servers — nothing to export, sell, or leak from our side
  • does not mark a line paid or change remaining balances

  • does not replace officer judgment or OSIL review
